# LONG GAME: LAST STAND

A rebuilt side-scrolling survival shooter made with C# Windows Forms. The game is designed for Windows and uses the .NET Framework 4.7.2.

## Run

Double-click `Long_game.exe`. Keep the `Assets` folder beside the executable. To edit the project, open `Long_game.csproj` in Visual Studio and build it.

## Controls

- **A / D** or **Left / Right**: move
- **Space / W / Up**: jump
- **Left mouse button** or **Ctrl**: fire
- **R**: reload
- **Shift**: dash (briefly avoids damage; cooldown applies)
- **Q**: melee attack
- **P / Esc**: pause or resume
- **Enter**: start or restart

Survive the route, collect ammo and medical supplies, defeat the boss, then reach the exit. The game includes multiple infected types, a scrolling city, a boss encounter, animated sprites, damage effects, and a score and kill counter.
